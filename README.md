# Повний цикл розробки: конспект IT-Марафону 2026

Неофіційний навчальний конспект на Astro. Чиста статика: без островів і фреймворків.

## Команди

| Команда | Що робить |
| :-- | :-- |
| `pnpm install` | Встановлює залежності |
| `pnpm dev` | Запускає локальний сервер на `localhost:4321` |
| `pnpm build` | Збирає сайт у `./dist/` |
| `pnpm preview` | Показує зібраний сайт локально |

## Деплой на GitHub Pages

Сайт збирається й публікується автоматично через GitHub Actions
(`.github/workflows/deploy.yml`) після кожного пушу в гілку `main`.

Один раз після створення репозиторію:

1. Запушити цю папку як корінь репозиторію в гілку `main`.
2. У репозиторії: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Дочекатися зеленого запуску на вкладці **Actions**. Адреса сайту буде на тій самій сторінці
   **Settings → Pages**.

Адресу сайту і шлях (`https://ім'я.github.io/назва-репо/`) workflow визначає сам і передає в
збірку через змінні `SITE_URL` і `BASE_PATH`, тож вручну в конфігу нічого міняти не треба.
Для локальної розробки використовуються заглушки з `astro.config.mjs`.

## Як це влаштовано

- `src/pages/posts/*.md` — статті й конспекти; порядок задає поле `order`, розділ — `section`.
- `src/pages/glossary.astro` — словник жаргону; нові слова додаються в масив на початку файлу.
- `src/components/Card.astro` — картка, якою оформлено всі списки.
- `src/middleware.ts` — під час збирання підсвічує слова про ШІ і додає до внутрішніх
  посилань шлях сайту на GitHub Pages.
- `public/og.png` — картинка для прев'ю посилань у месенджерах.
- Індексацію пошуковиками вимкнено тегом `robots` у `src/layouts/BaseLayout.astro`.
